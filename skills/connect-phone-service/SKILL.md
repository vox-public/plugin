# connect-phone-service

제품 호출에는 [공통 실행 계약](../../references/execution-contract.md)을 적용한다. 내장/외부의 질문·음성·파일 차이는 [호스트 연결](../../references/host-adapters.md)을 따른다. 도구는 연결된 서버가 제공하는 실제 이름과 스키마를 확인한 뒤 사용한다.

## 먼저 확인
보유 번호인지 새 번호/대표번호/발신표기번호가 필요한지 구분한다. `list_numbers/get_number`와 실제 신청 조회로 소유·상태·연결 agent/버전을 읽는다. 원하는 변경이 명확하면 이미 위임된 범위를 다시 승인받지 않는다. 구매 종류·대상·비용 등 결과를 바꾸는 미확정 입력은 확정해야 한다.

## 번호와 연결
보유 번호는 `set_number_agents` 등 실제 연결 계약을 따른다. 새 번호는 지원되는 목록/구매, 대표번호·표기번호·심사는 각 신청 도구의 요건을 확인한다. 번호 확보와 agent 연결, 수신 라우팅/전환을 서로 다른 단계로 표시한다. 인증·서류를 스킬/작업 파일에 무차별 복사하지 않는다.

## 완료 근거
신청 ID·현재 상태만 있으면 ‘신청 접수’다. 심사 승인을 약속하거나 승인 후 자동 재개를 예약하지 않는다. 연결을 저장했다면 실제 agent/버전·번호 설정을 재조회하고 통제된 수신 시험으로 결과 callId를 확인한다. 브라우저 음성 시험으로 전화망 수신을 검증했다고 말하지 않는다.

## 오류와 다음 행동
심사 대기면 필요한 사용자 행동과 조회 대상을 제공한다. 구매/신청 응답이 불명이면 [복귀 규칙](../resume-agent-work/SKILL.md)을 따른다. 인바운드 설정 요청을 실고객 아웃바운드 실행으로 바꾸지 않는다. desk 상담원 큐/이어받기 기능은 이 Agents 모듈에서 추정 실행하지 않는다.
